# Cardputer Morse Decoder

基于Cardputer的M5Stack摩斯电码翻译器。

![App Screenshot](20250814_174444.jpg) 
![App Screenshot](20250814_174456.jpg) 

## 主要功能

*   **双向翻译**: 支持文本与摩斯电码之间的即时互译。
*   **播放演示**: 通过声音和屏幕背光闪烁，以标准的10 WPM速度演示摩斯电码。
*   **扬声器控制**: 可在菜单中轻松开启或关闭声音。
*   **常用预设**: 快速加载如 "SOS", "CQ" 等常用短语，方便练习和使用。
*   **滚动输出**: 支持长文本翻译结果的上下滚动浏览。

## 如何使用

*   **输入**: 直接使用键盘输入文本或摩斯电码。
*   **翻译**: 按 `Enter` 键执行翻译。
*   **菜单**: 按 `Tab` 键打开功能菜单。
*   **导航**: 使用 `;` (上) 和 `.` (下) 在菜单中导航，按 `Enter` 确认。
*   **滚动**: 使用 `[` (上) 和 `]` (下) 滚动浏览输出结果。

## 如何部署

*  访问[uiflow2.m5stack.com](https://uiflow2.m5stack.com/)，导入.m5f2项目文件
*  连接你的cardputer，运行代码
